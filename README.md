# pairwise-astc-codec

同一张法线贴图在手机上正常，切到 PC 后金属表面出现一块块方格，换角度还有接缝：ASTC 按固定 8×8 块压缩，法线贴图的端点和权重没有按通道单独量化；块边界双线性采样跨块，法线被插成平面；sRGB 颜色贴图和线性法线贴图共用一套质量参数，颜色发灰；带 alpha 的 UI 图集被压成不透明块，边缘黑边；长条图和 cubemap 按总分辨率选块尺寸，出现大量空块；mip 在压缩前生成，缩小后高频细节丢失；法线重建没有归一化，光照出现暗斑；批量压缩按文件顺序处理，单张失败整批中断；不同平台的 ASTC 解码器对边界块处理不一致；纹理数组的层间边界没有单独处理，跨层采样串图；压缩缓存只按路径，改图后仍命中旧块；HDR 纹理按 8bit 端点压缩，高光被截断；压缩线程和资源上传并发，上传了半张图。assets/astc_codec.py 是核心，tests/test_astc_codec.py 15个红。要修的是：按通道量化；块边界采样；色彩空间分离；alpha 保留；按形状选块；压缩后 mip；法线归一化；批量错误隔离；平台一致性；纹理数组隔离；缓存版本；HDR 端点；上传同步。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。

子方向：图形渲染；任务类型：Bugfix；语言/框架：Python 3, pytest；环境可复现等级：无外部依赖。
